# 샘플 블로그 데이터 (테스트용)

이 폴더는 kwjmblogdocs(블로그 프로젝트)가 실제로 만드는 데이터 구조(posts.json,
media-meta.json, categories.json, settings.json, uploads/YYYY/MM/파일)를 그대로 흉내낸
샘플 데이터입니다. 블로그 앱을 따로 실행하지 않고도 "블로그에서 가져오기" 기능을
바로 테스트해볼 수 있습니다.

## 사용법

1. 이 앱(aivideodocs)을 `yarn dev`로 실행합니다.
2. 헤더에서 "블로그에서 가져오기"를 클릭합니다.
3. "블로그 데이터 폴더 연결" 버튼을 누르고, 폴더 선택 창에서 **바로 이 폴더**
   (`public/sample-blog-data`)를 선택합니다.
4. 제주 가족 여행을 소재로 한 글 3개(사진 5장 + 영상 1개)가 나타납니다.
5. 글을 선택한 뒤:
   - "채팅으로 가져오기" → 채팅에서 대화하며 스토리보드를 다듬고 싶을 때
   - "AI로 바로 스토리보드 만들기" → 대화 없이 바로 스토리보드를 만들고 싶을 때 (AI 연결 필요)

## 데이터 구성 의도

- 1번째 글(협재 해변): media-meta.json에 캡션/장소가 등록된 "정식" 미디어 경로를 테스트합니다.
- 2번째 글(새별오름·카페): 마찬가지로 media-meta.json 경로를 테스트합니다.
- 3번째 글(노을·흑돼지): media-meta.json 없이 본문 `<img>` 태그의 `title`/`data-location`
  속성만으로 캡션/장소를 알아내는 "본문 직접 추출" 경로를 테스트합니다.

이미지는 실제 사진이 아니라, 어떤 장면인지 알아보기 쉽도록 텍스트를 넣은 샘플
플레이스홀더 이미지/영상입니다.
