# 샘플 미디어 폴더 (테스트용)

블로그 데이터 없이, 그냥 사진/영상 파일만 있는 "미디어 폴더 연결" 기능을 테스트하기
위한 샘플 폴더입니다. 캡션이나 장소 정보가 전혀 없는, 순수 파일명뿐인 상태를
일부러 재현했습니다 (실제로 이런 폴더를 연결하는 사용자가 훨씬 많기 때문입니다).

## 사용법

1. 헤더에서 "미디어 라이브러리"를 클릭합니다.
2. "미디어 폴더 연결"을 누르고, 폴더 선택 창에서 **바로 이 폴더**
   (`public/sample-media`)를 선택합니다.
3. 사진/영상이 격자로 나타납니다.
   - 평소처럼 하나씩 클릭하면 현재 선택된 장면에 바로 적용됩니다.
   - "여러 개 선택해서 AI로 만들기"를 켜고 원하는 순서대로 여러 장을 고른 뒤
     "AI로 스토리보드 만들기"를 누르면, 고른 순서 그대로 각 사진/영상에 어울리는
     나레이션이 붙은 새 스토리보드가 만들어집니다 (AI 연결 필요).

파일명에서 대략적인 내용을 유추할 수 있게 지었지만(예: jeju_sunset_hamdeok.jpg),
실제 캡션/장소 데이터는 없는 상태이므로 AI가 이 파일들만으로 스토리보드를 만들 때
"캡션 없는 사진" 케이스를 정확히 테스트할 수 있습니다.
